# Smart City Information Website

## About the Project
The Smart City Information Website is a simple website developed using HTML, CSS, and JavaScript. Its purpose is to provide information about smart city initiatives, public services, transportation, and sustainable urban development.

The website helps visitors understand how technology and smart planning can make cities cleaner, safer, and more convenient.

## Features
- **Home Page:** Introduces the concept of a smart city.
- **Smart City Initiatives:** Provides information about smart infrastructure and energy.
- **Public Services:** Covers healthcare, water management, and waste management.
- **Smart Transportation:** Explains public transport, electric vehicles, and smart parking.
- **Sustainable Development:** Highlights green spaces, solar energy, and environmental protection.
- **Images:** Uses images to make the website attractive and informative.
- **Hover Effects:** Changes the appearance of navigation links, buttons, and cards when the mouse moves over them.
- **Contact Form:** Allows visitors to enter their name, email, select a service, and submit suggestions.
- **Response Display:** Shows the submitted information on the webpage.

## Technologies Used
- **HTML:** Creates the structure and content of the website.
- **CSS:** Adds colors, layouts, images, hover effects, and responsive styling.
- **JavaScript:** Handles form submission and displays the entered information.
- **Unsplash Images:** Provides online images for the website.

## How to Run the Project

1. Download or copy the project files into a folder named `SmartCity`.
2. Open the folder in Visual Studio Code.
3. Make sure `index.html` and `style.css` are in the same folder.
4. Open `index.html` in a web browser, or use the Live Server extension in VS Code.
5. Navigate through the website and test the hover effects.
6. Fill out the contact form and click **Submit Response** to see the entered details.

## Purpose of the Project

The main purpose of this project is to demonstrate basic web development concepts through a practical example. It shows how HTML, CSS, and JavaScript can work together to create an informative and interactive website.

## Limitations

- The website does not fetch live smart city data.
- The contact form displays responses on the webpage but does not save them permanently or send them to a server.
- Online images require an internet connection.
- The contact details and website content are illustrative.

## Future Improvements

- Add a database to store form responses.
- Include live weather and traffic information.
- Add a map showing public services and important city locations.
- Provide a citizen complaint and feedback system.
- Add more accessibility features and local language support.
